# BizBoost AI Business Testing Mode

Drop `public/test-mode.html` into the BizBoost AI PWA's `public/` folder.

Open `/test-mode.html` to:
- record real business testers
- rate usefulness, naturalness, and likelihood of use from 1–5
- save feedback locally
- see simple averages
- export a CSV for analysis

It does not contact businesses or send results anywhere. A production version should use secure authentication and a database.
